What Is MuXic?

MuXic is a community-driven music PWA (Progressive Web App) where users discover songs via YouTube and SoundCloud search, vote on a Song Board, share a Mixed Queue jukebox, contribute to a Daily Playlist, and recommend songs in a forum-style board. No account creation or login is required — each browser gets a unique anonymous identity automatically.

The app is designed as a shared music station: the community collectively curates what's trending, what's in the jukebox, and what's recommended today. Songs that earn enough votes graduate to permanent public status.

Architecture Decisions

Anonymous Identity
No login required. A UUID is generated and stored in localStorage on first visit. The user is auto-registered in the database on first profile view.
Contract-First API
The OpenAPI spec (lib/api-spec/openapi.yaml) is the single source of truth. Orval generates both the frontend React Query hooks and the backend Zod validation schemas from it.
Storage Tiers
limited (48h expiry) → permanent (user-promoted) → public_limited (community, 48h) → public_download (graduated via 50 votes, permanent)
Anti-Spam
Queue limited to 3 songs/hour per user (DB count). Forum has 30s cooldown (localStorage). Daily locked to 1 song/user/day. Votes and vetos deduplicated at DB level.
Proxy Routing
A global reverse proxy routes traffic by path: / → music-app, /api → api-server. Services never talk to each other directly.

Features

🏠 Home

  • Community stats: total songs, members, votes, forum posts
  • Trending Now: top 5 songs by votes in last 24h (falls back to all-time if no recent votes)
  • Today's Daily Playlist preview (first 5 songs)
  • Mixed Queue status (shown when songs are queued)

🔍 Search

  • YouTube + SoundCloud tabs
  • Real API search when YOUTUBE_API_KEY is set; falls back to mock data otherwise
  • Play preview directly from search results (without saving)
  • Import button: saves song as limited (48h) to your library and auto-nominates it to the Song Board

📚 Library

  • Personal song collection (only your songs, filtered by UUID)
  • Storage type badges: Limited (amber), Permanent (green), Public Limited (blue), Public Download (pink)
  • Countdown timers on limited songs (hours and minutes remaining)
  • Sort by: newest, oldest, title, artist, most voted
  • Filter by storage type, text search by title/artist
  • Actions: Play, Share to inbox, Promote to permanent, Delete
  • Share modal: pick a user, add an optional message, sends to their inbox

🎵 Playlists

  • Create named personal playlists
  • Add any of your library songs to a playlist (prevents duplicates)
  • Remove songs from a playlist
  • Play songs directly from within a playlist
  • Delete playlists

🏆 Song Board

  • Hot tab: songs ranked by votes in the last 24 hours
  • Legends tab: all-time highest vote count
  • Mini Board tab: all nominated songs, newest first (starting ground for new imports)
  • Vote on songs — deduplicated per user per song at the DB level
  • Already-voted songs show a disabled highlighted button
  • Auto-graduation: when a song reaches 50 votes, it upgrades to public_download storage and its expiry is cleared permanently

🎚️ Mixed Queue (Shared Jukebox)

  • Community jukebox — anyone can add songs
  • Token system: each user gets 3 tokens per hour; visual dot meter shows usage
  • Add from your library (songs already in queue are disabled)
  • Veto system: any user can veto a song; at exactly 3 vetos the song is auto-removed
  • Vetos are deduplicated (can't veto the same song twice)
  • Play button removes the song from the queue and starts playing it
  • First song in queue is highlighted as "up next"

📅 Daily Playlist

  • Each user can submit exactly 1 song per day
  • After submitting, the button disappears and a "come back tomorrow" message shows
  • Resets at midnight (server date-based)
  • Archive tab: browse past daily playlists grouped by date

💬 Forum (Recommendation Board)

  • Post song recommendations or ask for suggestions
  • Mood tags: #Sad, #Happy, #Gym, #Study, #Chill, #Party, #Focus, #Sleep
  • Filter posts by mood tag
  • Paginated (20 posts per page)
  • 30-second anti-spam cooldown between posts (enforced client-side via localStorage + server-side check)
  • Threaded replies: click a post to expand its reply thread and add a reply

👤 Profile

  • Auto-created on first visit with a display name like "User_abc123"
  • Edit display name (inline edit, updates instantly)
  • Stats: Reputation points, songs nominated, songs uploaded
  • Badges: Lyricist, Music Guru, Nominator (awarded by activity)
  • Activity tab: timeline of nominations, daily submissions, and forum posts
  • Inbox tab: songs shared to you by other users, with sender name and optional message
  • Delete account: removes all profile data, clears local identity, returns to home

🎧 Full Player

  • Full-screen player at /player
  • Album art, song title, artist, album
  • Seek bar with time display (current / total)
  • Volume slider
  • Shuffle toggle
  • Repeat modes: Off → Repeat One (🔂 "1") → Repeat All (🔁 "∞")
  • Sleep timer: 15 min / 30 min / 60 min with live countdown and cancel button
  • Source and storage type badges
  • Media Session API: integrates with OS lock screen and notification controls (play/pause/next/prev + album art)

📱 Mini Player

  • Persistent bar at the bottom of every page (except the full player)
  • Shows song cover art, title, artist
  • Quick play/pause and next buttons
  • "Full player" link to expand
  • On desktop: positioned to the right of the sidebar; on mobile: above the bottom nav bar

Database Schema

songs

id, title, artist, album, duration, coverUrl, source, sourceUrl, storageType, category, tags[], userId, expiresAt, voteCount, isPublic, createdAt

users

userId (UUID), displayName, reputation, badges[], createdAt

board_entries

id, songId, nominatedBy, voteCount, createdAt

votes

id, songId, userId, createdAt — unique per (songId, userId)

queue

id, songId, userId, vetoCount, position, createdAt

queue_vetos

id, queueId, userId — unique per (queueId, userId)

daily_playlist

id, songId, userId, date (YYYY-MM-DD), createdAt

forum

id, userId, content, moodTag, parentId (for replies), createdAt

playlists

id, name, userId, isPublic, createdAt

playlist_songs

playlistId, songId, addedAt — unique per (playlistId, songId)

inbox

id, fromUserId, toUserId, songId, message, createdAt
